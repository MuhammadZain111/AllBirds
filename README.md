# 🛍️ SoftBirds - Modern E-Commerce Platform

SoftBirds is a full-stack modern e-commerce application built with **Next.js**, **Node.js**, **Express.js**, and **MongoDB**. The platform provides a secure authentication system, responsive user interface, product management, shopping cart functionality, and an optimized shopping experience.

🌐 **Live Demo:** https://softbirds.vercel.app/

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/softbirds.git
```

```bash
cd softbirds
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment Variables

Create a `.env.local` file in the project root.

```env
NEXTAUTH_URL=

NEXTAUTH_SECRET=

MONGODB_URI=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

FACEBOOK_CLIENT_ID=
FACEBOOK_CLIENT_SECRET=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

---

## Run Development Server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
